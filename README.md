# 🛒 Dukkan App

Dukkan is a modern, native Android B2C e-commerce application designed to provide a seamless, hassle-free shopping experience for users.

## 🛠 Tech Stack
* **Platform:** Android
* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
* **Backend & Database:** [Firebase Firestore](https://firebase.google.com/docs/firestore)
* **Authentication:** Firebase Auth (Email/Password, Google, Apple)
* **Architecture:** MVVM (Model-View-ViewModel) 
* **Asynchronous Programming:** Kotlin Coroutines & Flow

## ✨ Key Features
* **Multi-Language Support:** Fully localized in English, Arabic (RTL support), and French.
* **Authentication:** Secure login and sign-up flows including social logins (Google/Apple) and guest mode.
* **Product Discovery:** Browse thousands of products seamlessly.
* **Hassle-Free Checkout:** Quick cart management and checkout process.
* **Modern UI:** Built entirely with Jetpack Compose following modern Material guidelines.

## 🚀 Getting Started

### Prerequisites
* [Android Studio](https://developer.android.com/studio) (Latest stable version recommended)
* JDK 17 or higher

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Android-Dukkan-App.git
   ```
2. Open the project in Android Studio.
3. **Firebase Setup:**
   * Go to the [Firebase Console](https://console.firebase.google.com/).
   * Create a new project or select an existing one.
   * Register a new Android App using the package name `com.example.dukkanapp`.
   * Download the `google-services.json` file.
   * Place the `google-services.json` file inside the `app/` directory of this project.
4. Sync the project with Gradle files.
5. Build and run the app on an Android emulator or a physical device.
